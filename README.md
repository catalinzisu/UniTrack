# UniTrack

## 📖 Descriere
O aplicație web dedicată studenților, care centralizează materialele de curs, oferă un sistem de rating pentru profesori și examene, și include remindere pentru sesiune. Totul este filtrat inteligent pe baza profilului studentului (Facultate, Specializare, An). 
*Proiect realizat pentru cursul de Angular.*

## ✨ Funcționalități Principale (Conform Barem)
* **Autentificare & Profiling:** Login/Register cu Fake API și profilare pe an/specializare.
* **Filtrare Smart:** Materiale și examene afișate strict pe baza profilului logat.
* **Sistem de Rating:** Evaluarea profesorilor (UI custom cu steluțe).
* **Operațiuni CRUD:** Adăugare, editare și ștergere a materiilor prin modale NgZorro.
* **Căutare Reactivă:** Searchbar realizat folosind Angular Signals.
* **Reminder Sesiune (Bonus):** Calcul automat al zilelor rămase până la examen (folosind `date-fns`).

## 🛠️ Tehnologii Folosite
* Angular 20 (Standalone components)
* NgZorro (UI Library)
* Fake API (Reqres.in)
* RxJS & Angular Signals

## 🚀 Cum să rulezi proiectul local
1. Clonează repository-ul: `git clone [link-ul-tau-de-github]`
2. Instalează dependențele: `npm install`
3. Pornește serverul de dezvoltare: `ng serve`
4. Accesează aplicația în browser la adresa: `http://localhost:4200`
